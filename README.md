# VPN Installer

Установщик VPN на **чистый** сервер: VLESS + XHTTP + Reality через панель 3x-ui.
Дополнительно может поставить **AmneziaWG** (без Docker) и дать удобное управление клиентами.
Запускается двойным кликом, спрашивает адрес сервера и несколько опций, всё делает сам.

## Что нужно

- Чистый сервер **Ubuntu 20.04/22.04/24.04** или **Debian 11/12** (x86_64 или aarch64), 512 MB RAM и больше.
- Порты **443/TCP**, **UDP 51820** (AmneziaWG) и **443/UDP** (Hysteria2) свободны и не закрыты облачным firewall провайдера.
- Доступ root: пароль или SSH-ключ.
- Windows 10/11 — ничего доустанавливать не нужно, PowerShell и ssh уже есть.

## Как запустить

1. Распакуйте папку целиком (не запускайте файлы из ZIP-архива).
2. Двойной клик по **`Запустить установку VPN.cmd`** — откроется меню.
3. Выберите **`1` — Установить VPN на сервер**.
4. Введите IP сервера и SSH-порт (обычно 22).
5. Выберите способ входа: SSH-ключ или пароль root.
6. Ответьте на вопросы: панель, имена клиентов, маскировка, Hysteria2, AmneziaWG, белые списки, защита сервера, проверка.
7. Дождитесь надписи «Готово» — откроется страница с QR-кодами, ссылками и оценкой проверки.

### Меню

| Пункт | Что делает |
|---|---|
| `1` | Установка на новый сервер |
| `2` | Продолжить прерванную установку (`-Resume`) |
| `3` | Добавить клиентов, статус, backup, панель |
| `4` | Проверить сервер и получить оценку |
| `5` | Открыть панель 3x-ui через туннель |
| `6` | Открыть последнюю папку с результатом |
| `7` | Справка |

Всё запускается из одного файла — `Запустить установку VPN.cmd`.

## Что получится

Рядом появится папка `vpn-result-<адрес>-<дата>`:

| Файл | Зачем |
|---|---|
| `index.html` | Открыть в браузере: QR, ссылки, данные панели |
| `share-<имя>.html` | Отправить получателю — там только его ключ |
| `qr-<имя>.png` | QR для телефона |
| `links.txt` | Все ссылки списком |
| `split-tunnel.txt` | Как включить белые списки в клиенте |
| `amnezia-<имя>.conf` | Готовый конфиг для AmneziaVPN (если AmneziaWG включён) |
| `amnezia.html` | QR и инструкция для AmneziaWG |
| `open-panel.cmd` | Открыть панель через SSH-туннель |
| `Управление VPN.cmd` | Меню: добавить/удалить клиента, статус, backup |
| `Добавить клиента VPN.cmd` | Быстро добавить нового VLESS-клиента |
| `Добавить AmneziaWG клиента.cmd` | Быстро добавить клиента AmneziaWG |
| `install.log` | Лог установки, если что-то пошло не так |
| `result.json` | Машинные данные установки для разбора проблем |
| `connection.json` | Данные подключения для меню управления |

## Управление клиентами

В папке результата есть три файла:

- **`Добавить клиента VPN.cmd`** — спросит имя, срок и лимит трафика, создаст клиента и откроет страницу с QR.
- **`Добавить AmneziaWG клиента.cmd`** — то же для AmneziaWG, сохранит `.conf` и QR.
- **`Управление VPN.cmd`** — полное меню: список клиентов, ссылка/QR, удаление, статус сервера, backup, открыть панель.

Меню работает через SSH, панель наружу не открывается. Пароль SSH при входе по паролю нужно ввести один раз за запуск.

## Защита

- **Firewall**: открыты только SSH, TCP 443, UDP-порт AmneziaWG (по умолчанию 51820) и (если включён) UDP 443. Всё остальное закрыто.
- **Панель** по умолчанию слушает `127.0.0.1` — из интернета недоступна. Можно включить доступ по HTTPS (самоподписанный сертификат) — тогда порт панели открывается осознанно.
- **Порт подписок 3x-ui (2096)** закрывается firewall'ом: подписки не нужны, а порт иначе слушает наружу.
- **Пароли и путь панели** генерируются случайными, логин и пароль — 20 и 32 символа.
- **fail2ban**: 5 неудачных попыток SSH с одного адреса → бан на 1 час; повторные нарушители — на неделю.
- **Защита сервера (опция, по умолчанию включена)**: SYN-cookies, запрет redirects и source route, отбрасывание битых пакетов, автоматические обновления безопасности без перезагрузки. SSH-порт и `sshd_config` не меняются.
- **Проверка после установки**: установщик сам смотрит службы, порты, TLS, панель, firewall и выход в интернет, затем проверяет доступность с вашего ПК и ставит оценку (0–100%). Оценка и список проверок сохраняются в `index.html` и `README.txt`.
- **Автопроверка**: раз в 2 минуты проверяется, что x-ui и Xray живы; если Xray пропал — панель перезапускается.
- **Защита от блокировки SSH**: правила firewall применяются с таймером отката на 15 минут. Если что-то пойдёт не так — доступ вернётся сам.
- **Проверка загрузок**: установщик 3x-ui скачивается с GitHub по тегу и сверяется по SHA-256; `plink.exe` проверяется по SHA-256 и подписи автора.
- **Docker и Amnezia не трогаются**: если на сервере есть Docker, политика INPUT не меняется. Если уже стоит Amnezia/AmneziaWG — установщик её не трогает и пропускает свой AmneziaWG.
- **AmneziaWG без Docker**: ставится официальный пакет Amnezia из PPA, отдельный интерфейс `awg0` на своём UDP-порту. На старых ядрах (Ubuntu 22.04, 5.15) установщик сам правит исходник модуля (`timer_delete` → `del_timer_sync`) и собирает его через DKMS — перезагрузка не нужна. Клиентские `.conf` и QR-коды создаются автоматически.

## Если установка прервалась

Если 3x-ui уже установился, а настройка VPN не дошла до конца (например, панель не ответила), не переустанавливайте сервер. Закройте старое окно установщика и запустите двойным кликом:

```text
Продолжить установку VPN.cmd
```

Он найдёт существующую панель, возьмёт её данные с сервера и завершит настройку. Если запускаете из командной строки, можно добавить ключ `-Resume` к основному файлу.

Если панель 3x-ui перестала отвечать во время установки, установщик сам перезапустит её и дождётся нового процесса. Если ошибка повторилась — пришлите `install.log` тому, кто ставил VPN. В логе есть ключи и пароли, публиковать его нельзя.

## Если соединение отваливается

VPN может страдать от блокировок провайдера или РКН. Что проверить по порядку:

1. **Сервер жив?** `systemctl status x-ui` — служба должна быть `active (running)`.
2. **Порт слушается?** `ss -ltnp | grep :443` — должен быть Xray.
3. **IP доступен?** С другого интернета (мобильный) откройте `https://ifconfig.me` с VPN — если показывает адрес сервера, всё работает.
4. **Домашний провайдер режет?** Попробуйте с мобильного интернета. Если там работает, а дома нет — дело в домашнем провайдере, а не в сервере.
5. **Заблокировали SNI?** В панели откройте inbound → Reality → `serverNames` и замените домен на другой из списка (`www.microsoft.com`, `www.apple.com`, `www.cloudflare.com`). Затем пересоздайте ссылки.
6. **Заблокировали IP?** Никакие настройки сервера не помогут — нужен новый IP или новый VPS. Это главная причина «отваливается насовсем».
7. **UDP режут?** Hysteria2 не заработает. VLESS по TCP — основной и самый устойчивый.


## Важно

- Установщик рассчитан на **чистый** сервер. Если 3x-ui уже стоит или порт 443 занят — он остановится и ничего не изменит. Для незавершённой установки есть режим `-Resume`.
- Он **не перезагружает** сервер, **не трогает Docker** и **не меняет SSH-порт**.
- Панель по умолчанию слушает только `127.0.0.1` — открывайте её через `open-panel.cmd`. Если выбрали «панель из интернета», вход идёт по HTTPS-ссылке, а браузер один раз предупредит о самоподписанном сертификате.
- Ссылка = ключ доступа к VPN. Не публикуйте её. Другим людям отправляйте только `share-<имя>.html`.
- Hysteria2 и AmneziaWG — опции. Многие провайдеры режут UDP, тогда используйте VLESS: он основной и работает всегда.
- Если на сервере уже есть Amnezia (Docker или `awg0`) — установщик не меняет её и пропускает установку AmneziaWG.

## Если что-то не так

- Запустите **`Запустить установку VPN.cmd`** → пункт `4`: проверка покажет, что именно не работает, и поставит оценку.
- `install.log` — полный лог установки.
- На сервере: `systemctl status x-ui`.
- Перезагрузка сервера не требуется. Если всё же нужна — сначала спросите того, кто ставил.
